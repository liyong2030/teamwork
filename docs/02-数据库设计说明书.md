## 1. 数据模型总览

系统划分为四个数据域：

| 域 | 说明 | 包含实体 |
|---|---|---|
| **组织域** | 人、部门、成员关系、请假 | `departments`、`users`、`department_members`、`leave_requests` |
| **项目域** | 项目、任务、协作人、状态流水 | `projects`、`project_members`、`tasks`、`task_collaborators`、`task_status_logs` |
| **周报域** | 点名名册、周报、条目、修订、定版快照 | `weekly_roll_calls`、`weekly_reports`、`weekly_report_items`、`weekly_report_revisions`、`weekly_stat_snapshots` |
| **系统域** | 审计、通知、系统配置 | `audit_logs`、`notifications`、`system_settings` |

### 1.1 ER 关系（文字描述）

```
departments 1 ──< department_members >── 1 users
departments 1 ──< projects
users       1 ──< tasks (owner)          >── 1 projects
tasks       1 ──< task_collaborators >── 1 users
tasks       1 ──< task_status_logs   >── 1 users (operator)
users       1 ──< weekly_reports     >── 1 weekly_roll_calls(标记 required)
weekly_reports 1 ──< weekly_report_items >──  tasks (可空)
weekly_reports 1 ──< weekly_report_revisions
weekly_roll_calls / weekly_reports ──> weekly_stat_snapshots (按 部门+周)
users       1 ──< leave_requests     >── 1 users (approver)
users       1 ──< audit_logs / notifications
```

## 2. 公共约定

### 2.1 通用字段

所有业务表均包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | `BIGINT` PK | 雪花风格自增序列（PostgreSQL `BIGSERIAL`，SQLite `INTEGER AUTOINCREMENT`） |
| `created_at` | `TIMESTAMP WITH TIME ZONE` | 创建时间，服务端 `now(UTC)` |
| `updated_at` | `TIMESTAMP WITH TIME ZONE` | 更新时间，`onupdate` 自动刷新 |

统一采用 **UTC 存储 + 应用层转本地时区（Asia/Shanghai）**，避免夏令时与跨时区统计错位。

### 2.2 枚举定义

```text
任务状态 TaskStatus      : todo | in_progress | blocked | done | cancelled
任务优先级 TaskPriority  : p0 | p1 | p2 | p3
项目状态 ProjectStatus   : planning | active | paused | archived
周报状态 ReportStatus    : draft | ontime | late | makeup | missing | by_proxy
周报条目 Section         : done | progress | risk | plan
周报条目来源 ItemSource  : auto | manual
请假状态 LeaveStatus     : pending | approved | rejected
通知渠道 NotifyChannel   : inbox | email
```

SQLite 无原生枚举，使用 `String` + 应用层 `CHECK 约束模拟`；PostgreSQL 使用原生 `Enum` 类型（通过 SQLAlchemy `native_enum=True`）。

|---|---|---|---|---|
| `id` | BIGINT PK | N | — | 主键 |

| `full_name` | VARCHAR(64) | N | — | 姓名 |
| `hashed_password` | VARCHAR(255) | **Y** | NULL | Argon2id 哈希串；**统一身份认证账号为 NULL** |
| `auth_source` | VARCHAR(16) | N | `local` | 认证来源：`local` / `cas` / `oidc` / `ldap` / `saml` |
| `external_id` | VARCHAR(128) | Y | NULL | IdP 侧唯一标识（CAS 用户名 / OIDC `sub` / LDAP DN） |
| `is_active` | BOOLEAN | N | true | 在职状态；离职置 `false`，不物理删除 |

唯一约束：`uq_users_auth_source_external_id`（`auth_source`, `external_id`）

> **安全说明**：`users` 表不存储明文口令；Argon2id 参数（`time_cost=3`、`memory_cost=64MB`、`parallelism=4`）由 `core/security.py` 统一维护。
>
> **统一身份认证**：`auth_source != 'local'` 的账号**禁止本地口令登录**，其 `hashed_password` 为 NULL。
> `uq_users_auth_source_external_id` 保证同一 IdP 内的标识不会被绑定到两个账号
> （本地账号 `external_id` 为 NULL，受 SQL 的 NULL 不去重语义影响，不参与该约束）。
> 迁移 `49eaab6013e1` 会为存量账号回填 `auth_source='local'`。

### 5.6 周报五态迁移（互斥）

```
                  ┌─── 提交 ≤ 周五 18:00 ──────────────► ONTIME 准时
   (无记录) ──────┤
                  ├─── 周五 18:00 ~ 周一 09:30 提交 ───► LATE 迟到
                  │
                  └─── 周一 09:30 定版时仍无记录 ──────► MISSING 未提交
                                                          │
                                                          └─ 定版后补交 ─► MAKEUP 补交（独立计数，不回滚 MISSING 口径）

   任意时刻，组长代提交 ──────────────────────────────► BY_PROXY 代提交

   DRAFT 草稿 ──► 提交 ──► {ONTIME | LATE} ──► 修订 version+1（状态不变，留痕）
```

**核心规则**：准时率 = `ontime_count / required_count`。分母为点名名册人数，**固定不变**；补交只增加 `makeup_count`，不得回填 `missing_count`，确保历史数据可审计。

## 8. 数据完整性约束汇总

| 约束 | 类型 | 说明 |
|---|---|---|
| 一人一周一份周报 | 唯一约束 | `uq_weekly_reports_user_week` |
| 一人一周一个部门名册条目 | 唯一约束 | `uq_roll_calls_week_user_dept` |
| 禁止删除用户 / 任务 | 应用层软删 | `is_active = false`、`status = cancelled` |
| 任务状态变更必须留痕 | 应用层约定 | `services/task_service.change_status()` 唯一入口 |
| 周报提交后禁止原地修改 | 应用层 + 版本快照 | 修改走 `weekly_report_revisions` |
| 定版快照不可修改 | 应用层 | `finalized = true` 后拒绝写入 |

## 9. 兼容性说明

| 事项 | SQLite | PostgreSQL |
|---|---|---|
| 枚举 | `String(16)` + Python Enum 校验 | 原生 `Enum` |
| JSON | `JSON`（TEXT 存储） | `JSONB`（推荐，可走 GIN 索引） |
| 时间 | `DateTime(timezone=False)` 存 UTC naive | `TIMESTAMPTZ` |
| 自增 | `INTEGER PRIMARY KEY AUTOINCREMENT` | `BIGSERIAL` |
| 并发 | 单写者，仅适用于 ≤ 20 人团队 | 完整 MVCC，生产必选 |

> 开发环境使用 SQLite 完全可用，**但定时任务与 Web 在同一进程内共享 scheduler**，多副本部署时须改为独立 worker 进程或引入分布式锁，否则提醒会重复发送。生产建议使用 `--workers 1` + Nginx，或把 APScheduler 抽取为独立 service。
